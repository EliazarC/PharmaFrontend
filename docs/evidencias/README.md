# Evidencias de la matriz

Guarde aquí una captura por caso, con el nombre indicado en la columna «Evidencia» de la matriz
(por ejemplo `L-01.png`, `S-01.png`, `I-03_red.png`, `B-01.png`).

Reglas:
- Capturas reales de su navegador; no se incluyen capturas generadas.
- **No muestre el token JWT completo**: recórtelo o tápelo (deje solo `eyJ…`).
- En Red, muestre el método, la URL, el estado HTTP y, cuando corresponda, el encabezado `Authorization` recortado.
- En Aplicación > Almacenamiento de sesión, muestre la clave `pharmasoft.sesion` con el token recortado.
